# Cyc-VAE
De novo design of cyclic peptide using hierarchical approach. Particularly targets MDM2 by combining GRU-VAE with Metropolis-Hastings sampling and iterative HADDOCK fine-tuning. Optimizes and validates high-affinity binders, such as c[DPKNRFCG], with structure-based approach, with a low computational burden and with a stable binding.
